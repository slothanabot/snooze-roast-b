A one-line roast of an alarm clock that rings at 6am on a Saturday, for make.fun's "Snooze Button Roast" bounty. `main.py` writes the entry to `/output/entry.txt`.

The entry:

> My alarm rang at 6am on a Saturday, so I hit snooze so hard it filed a noise complaint - then woke me up anyway, out of spite.

## Run it

```sh
python3 main.py
```
